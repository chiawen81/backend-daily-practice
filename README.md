# Backend Daily Practice

個人後端工程 coding gym。

## 目標

- 每日約 10～15 分鐘實際 coding
- 提升獨立 coding 能力
- 提升 AI-generated code review 能力
- 累積常見 Backend Coding Patterns

## 目前主要學習

- C#
- LINQ
- ASP.NET Core

未來可能加入 SQL、Oracle 等後端主題。

課程 syllabus、每日題目與組織方式由學習系統負責；本 repository 只保存實際練習成果，並依每日 syllabus 的需要逐步新增內容。
